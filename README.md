# NullBloat

The Windows optimizer that proves it works.

NullBloat removes Windows bloat, tunes your PC for games and lowers input lag. Every change is saved, verified and can be undone exactly, and built-in benchmarks show whether it actually made your games faster.

**Download:** [latest release](https://github.com/vaughnponcee/nullbloat/releases/latest) (Windows 10 and 11, 64-bit)

This repository hosts NullBloat's releases and update files. Installed copies update themselves from here.

See [CHANGELOG.md](CHANGELOG.md) for what changed in each version.
