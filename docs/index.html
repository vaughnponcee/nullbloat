FAQ

Questions

Is it safe?

Setup offers to create a Windows restore point. Every setting is saved before it changes, checked afterwards, and can be put back exactly. NullBloat never turns off Windows Defender, the firewall or Windows Update.

Can it get me banned in games with anti-cheat?

No. It never opens, injects into or reads the memory of a game. It only changes normal Windows settings and spots running games by name.

Will it double my FPS?

Probably not, and anyone promising that is guessing. Gains depend on your PC and game. NullBloat measures the difference and tells you, including when there isn't one.

Does Pro expire?

No. It's a one-time payment.

Do you sell my data?

No. We never sell or share your information.

Which Windows versions work?

Windows 10 and Windows 11, 64-bit.
