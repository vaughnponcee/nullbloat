Questions

Is it safe?

NullBloat creates a Windows restore point during setup, saves every original setting before changing it, checks each change took effect, and can put back the exact original. It never disables Windows Defender, the firewall or Windows Update.

Will it get me banned in games with anti-cheat?

No. NullBloat never opens, injects into or reads the memory of games. It only changes ordinary Windows settings, and recognises running games by name only.

Will it double my FPS?

Usually not, and anyone promising that is guessing. Gains depend on your PC and game. NullBloat measures the difference and tells you honestly, including when there is none.

Does Pro expire?

No. Pro is a one-time purchase with a lifetime license.

Which Windows versions are supported?

Windows 10 and Windows 11, 64-bit.
