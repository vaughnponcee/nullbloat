# Changelog

## 0.1.0
First release.
- Setup with a verified Windows restore point before any change
- 40+ reversible optimizations: gaming, input latency, network, visual, bloat and ads, privacy and telemetry
- Automatic game mode that applies settings while a game runs and restores them when it closes
- Games library (Steam, Epic, Riot, Roblox and Windows-detected games) with Play buttons and playtime
- FPS benchmarks with Intel PresentMon, bottleneck finder and honest before/after verdicts
- Network tools: ping, jitter, lag-under-load test, DNS speed test
- Cleanup, preinstalled app remover, installed programs, startup apps, drivers, diagnostics
- Pro: Auto-Tune, Stutter Doctor, Game-ready check, performance alerts, session reports, scheduled maintenance
- System tray, start with Windows, signed in-app updates
